# M4.3a Implementation Plan: Paper Trading Logs Explain Decisions End-to-End

**Status: ✅ COMPLETED**

## Objective
Ensure every decision made by the paper trading engine is fully logged with context, enabling post-hoc analysis and debugging.

## Success Criteria
- [x] Every signal generated is logged with timestamp, symbol, direction, and source strategy
- [x] Every risk evaluation is logged with pass/fail and violation details
- [x] Every order simulation is logged with requested vs filled price, slippage, and fees
- [x] Every portfolio update is logged (cash, positions, total value)
- [x] Logs are structured (JSON) for easy parsing
- [x] Log files are rotated daily to prevent disk space issues
- [x] A log viewer/parser script is available for analysis

## Implementation Steps

### Step 1: Create Decision Logger (`src/baet/paper/logging.py`)
Create a structured logging system for paper trading decisions.

**Key Features:**
- JSON-formatted log entries
- Contextual information (timestamp, symbol, decision type)
- Multiple log levels (INFO for normal flow, WARNING for risk violations, ERROR for failures)
- Daily log file rotation

**Log Entry Types:**
1. `SIGNAL_RECEIVED` - Strategy signal with metadata
2. `RISK_EVALUATION` - Risk check results
3. `ORDER_SIMULATED` - Order execution details
4. `PORTFOLIO_UPDATE` - Portfolio state changes
5. `ENGINE_EVENT` - Start/stop/error events

### Step 2: Integrate Logger into PaperTradingEngine
Update `PaperTradingEngine` to log all decisions.

**Integration Points:**
- In `_iteration()`: Log each iteration with timestamp
- When signal received: Log signal details
- When risk evaluated: Log risk check results
- When order simulated: Log fill details
- When portfolio updated: Log state changes

### Step 3: Integrate Logger into PaperPortfolio
Update `PaperPortfolio` to log all trades and state changes.

**Integration Points:**
- In `buy()`: Log trade details
- In `sell()`: Log trade details
- In `update_equity_curve()`: Log portfolio value updates

### Step 4: Integrate Logger into PaperOrderSimulator
Update `PaperOrderSimulator` to log order simulations.

**Integration Points:**
- In `simulate_buy()`: Log requested vs filled price, slippage, fees
- In `simulate_sell()`: Log requested vs filled price, slippage, fees

### Step 5: Create Log Configuration
Add logging configuration to `config/models.py` and `config/base.yaml`.

**Configuration Options:**
```yaml
paper:
  logging:
    enabled: true
    level: "INFO"
    directory: "logs/paper"
    rotation: "daily"
    max_files: 30
```

### Step 6: Create Log Analysis Script (`scripts/analyze_paper_logs.py`)
Create a script to parse and analyze paper trading logs.

**Features:**
- Parse JSON log files
- Filter by log type (SIGNAL, RISK, ORDER, etc.)
- Generate summary statistics
- Export to CSV for further analysis

### Step 7: Write Tests (`tests/test_paper_logging.py`)
Create comprehensive tests for the logging system.

**Test Coverage:**
- Test logger initialization
- Test each log entry type
- Test log file rotation
- Test log parsing
- Test integration with engine/portfolio/simulator

### Step 8: Update Documentation
Update `src/baet/paper/README.md` with logging documentation.
