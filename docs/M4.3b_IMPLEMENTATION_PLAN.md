# M4.3b Implementation Plan: Streamlit Dashboard for Paper Trading

**Status: ✅ COMPLETED**

## Objective
Create a Streamlit dashboard that shows current paper trading state and daily summaries, providing real-time visibility into paper trading performance.

## Success Criteria
- [x] Dashboard displays current portfolio state (cash, positions, total value)
- [x] Dashboard shows recent trades and their outcomes
- [x] Dashboard displays daily performance summaries
- [x] Dashboard shows risk metrics and alerts
- [x] Dashboard updates automatically (or with manual refresh)
- [x] Dashboard is accessible via `streamlit run` command
- [x] Dashboard handles missing data gracefully (when paper trading not running)

## Implementation Steps

### Step 1: Create Dashboard Module Structure
Create the dashboard module directory and files.

**Files to Create:**
```
src/baet/dashboard/
    __init__.py
    app.py           # Main Streamlit app
    components.py    # Reusable UI components
    data_loader.py   # Data loading from logs/state
```

### Step 2: Implement Data Loader (`data_loader.py`)
Create functions to load paper trading data from logs and state files.

**Key Functions:**
- `load_latest_state()` - Load most recent portfolio state
- `load_recent_trades(limit=50)` - Load recent trades from logs
- `load_daily_summary(date)` - Load or calculate daily summary
- `load_performance_metrics()` - Calculate Sharpe, drawdown, etc.
- `parse_log_file(log_file)` - Parse JSON log files

**Data Sources:**
- Paper trading log files (`logs/paper/paper_trading_YYYY-MM-DD.log`)
- Portfolio state files (if persisted)
- Equity curve data

### Step 3: Implement UI Components (`components.py`)
Create reusable Streamlit components.

**Components:**
- `render_portfolio_overview(portfolio_state)` - Cash, total value, position count
- `render_positions_table(positions)` - Current positions with P&L
- `render_recent_trades(trades)` - Recent trade history table
- `render_performance_metrics(metrics)` - Sharpe, Sortino, drawdown
- `render_risk_status(risk_state)` - Risk alerts and violations
- `render_equity_chart(equity_curve)` - Equity curve chart
- `render_daily_summary(summary)` - Daily P&L summary

### Step 4: Implement Main App (`app.py`)
Create the main Streamlit application with navigation.

**Pages/Sections:**
1. **Overview** - Current portfolio state, equity chart
2. **Positions** - Current holdings with unrealized P&L
3. **Trades** - Recent trade history
4. **Performance** - Metrics and charts
5. **Risk** - Risk status and alerts
6. **Logs** - Recent log entries viewer

**Features:**
- Auto-refresh toggle with configurable interval
- Date selector for historical views
- Export functionality (CSV download)
- Dark/light theme support

### Step 5: Create Dashboard Configuration
Add dashboard configuration to `config/models.py` and `config/base.yaml`.

**Configuration Options:**
```yaml
dashboard:
  enabled: true
  port: 8501
  theme: "dark"
  auto_refresh: true
  refresh_interval_seconds: 30
  max_recent_trades: 50
  max_log_entries: 100
```

### Step 6: Create Launcher Script
Create a script to launch the dashboard.

**Script:** `scripts/run_dashboard.py`
- Loads configuration
- Sets up Streamlit config
- Launches the app

**Usage:**
```bash
python scripts/run_dashboard.py
# or
streamlit run src/baet/dashboard/app.py
```

**Test Coverage:**
