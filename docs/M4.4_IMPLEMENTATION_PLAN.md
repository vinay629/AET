Create `docs/M4.4_STABILITY_CRITERIA.md` with:

1. **Uptime Requirements**
   - Paper trading engine runs continuously for full observation period
   - Automatic restart on failure (with state recovery)
   - Maximum downtime: < 5 minutes per incident

2. **Performance Requirements**
   - Memory usage stable (no continuous growth over 24 hours)
   - CPU usage reasonable (< 50% average on target hardware)
   - Log file size manageable (< 100MB per day)

3. **Data Integrity Requirements**
   - All trades properly logged
   - Portfolio state consistent (balance + equity = total value)
   - No missing data in equity curve
   - Log files parseable (valid JSON)

4. **Error Handling Requirements**
   - Graceful handling of network errors (Binance API)
   - Graceful handling of data errors (malformed candles)
   - All errors logged with context
   - No unhandled exceptions crashing the engine

### Step 2: Create Monitoring Script

Create `scripts/monitor_paper_trading.py`:

```python
"""Monitor paper trading stability during observation window."""

import time
import json
from pathlib import Path
from datetime import datetime, timedelta
import psutil
import requests

def check_process_running(script_name: str) -> bool:
    """Check if paper trading process is running."""
    for proc in psutil.process_iter(['pid', 'name', 'cmdline']):
        try:
            cmdline = proc.info['cmdline']
            if cmdline and script_name in ' '.join(cmdline):
                return True
        except (psutil.NoSuchProcess, psutil.AccessDenied):
            pass
    return False

def check_log_freshness(log_dir: str = "logs/paper") -> dict:
    """Check if log files are being updated."""
    log_path = Path(log_dir)
    if not log_path.exists():
        return {"status": "error", "message": "Log directory not found"}

    log_files = list(log_path.glob("paper_trading_*.log"))
    if not log_files:
        return {"status": "error", "message": "No log files found"}

    # Check most recent log file
    latest = max(log_files, key=lambda f: f.stat().st_mtime)
    mtime = datetime.fromtimestamp(latest.stat().st_mtime)
    age_seconds = (datetime.now() - mtime).total_seconds()

    return {
        "status": "ok" if age_seconds < 300 else "stale",
        "latest_log": str(latest),
        "last_update_seconds_ago": age_seconds,
        "log_size_mb": latest.stat().st_size / (1024 * 1024)
    }

def check_dashboard_accessible(port: int = 8501) -> bool:
    """Check if Streamlit dashboard is accessible."""
    try:
        response = requests.get(f"http://localhost:{port}", timeout=5)
        return response.status_code == 200
    except:
        return False

def send_alert(message: str, webhook_url: str = None):
    """Send alert (placeholder for email/Slack/Discord webhook)."""
    print(f"ALERT: {message}")
    if webhook_url:
        # Implement webhook notification here
        pass

def main():
    """Run monitoring loop."""
    print(f"Starting paper trading monitor at {datetime.now()}")

    while True:
        # Check process
        if not check_process_running("paper_trading"):
            send_alert("Paper trading process not running!")

        # Check logs
        log_status = check_log_freshness()
        if log_status["status"] != "ok":
            send_alert(f"Log issue: {log_status}")

        # Check dashboard
        if not check_dashboard_accessible():
            send_alert("Dashboard not accessible!")

        # Sleep for 5 minutes
        time.sleep(300)

if __name__ == "__main__":
    main()
```

### Step 3: Set Up Continuous Paper Trading

Create a startup script `scripts/start_paper_trading.sh` (or `.bat` for Windows):

**Windows (start_paper_trading.bat):**
```batch
@echo off
echo Starting paper trading observation...

:loop
python -m baet.paper.engine --config config/paper.yaml
echo Paper trading stopped with exit code %ERRORLEVEL%
echo Restarting in 10 seconds...
timeout /t 10
goto loop
```

**Linux/Mac (start_paper_trading.sh):**
```bash
#!/bin/bash
while true; do
    python -m baet.paper.engine --config config/paper.yaml
    echo "Paper trading stopped with exit code $?"
    echo "Restarting in 10 seconds..."
    sleep 10
done
```
