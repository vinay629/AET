# M5.2: Emergency Procedures for Tiny-Capital Live Pilot

**Status: Ready for M5.2 — Review before starting live pilot**

## Quick Stop Methods (Use ANY of these)

### Method 1: Emergency Stop File (Recommended)
```bash
# Creates emergency stop signal
touch EMERGENCY_STOP.txt

# To resume (remove the file)
rm EMERGENCY_STOP.txt
```

### Method 2: Dashboard Emergency Button
1. Open dashboard at http://localhost:8501
2. Go to "Control Panel" tab
3. Click **"EMERGENCY STOP"** button (red)

### Method 3: Binance Manual Cancellation
1. Log into Binance.com
2. Go to "Orders" → "Open Orders"
3. Cancel all open orders
4. Close all positions manually

### Method 4: Kill the Process
```bash
# Find and kill the trading process
Ctrl+C in the terminal running the bot

# Or find and kill by port
netstat -ano | findstr :8501
taskkill /PID <PID> /F
```

---

## Auto-Stop Triggers (System will stop automatically)

The system will automatically stop if ANY of these occur:
- Daily loss reaches **$10**
- Single position loss reaches **$5**
- **3 consecutive losing trades**
- Any execution error occurs
- Emergency stop file detected

## Daily Monitoring Checklist (3x per day)

### Morning Check (9-10 AM)
- [ ] Check open positions
- [ ] Verify stop-losses are set
- [ ] Review overnight P&L
- [ ] Check system health (dashboard)
- [ ] Confirm no unauthorized activity

### Midday Check (1-2 PM)
- [ ] Check open positions
- [ ] Review today's P&L
- [ ] Verify no new unauthorized orders
- [ ] Check system health

### Evening Check (6-7 PM)
- [ ] Close any open positions (if strategy says so)
- [ ] Final P&L calculation
- [ ] Check system health
- [ ] Document day's activity in daily log
- [ ] Decide: Continue tomorrow / Pause / Abort

## Notification Setup

### Telegram Webhook (Recommended)
1. Create Telegram bot via @BotFather
2. Get bot token and chat ID
3. Add to `config/live.yaml`:
```yaml
paper:
  notification_webhook: "https://api.telegram.org/bot<TOKEN>/sendMessage?chat_id=<CHAT_ID>&text="
```

### Discord Webhook
1. Create webhook in Discord channel
2. Add to `config/live.yaml`:
```yaml
paper:
  notification_webhook: "https://discord.com/api/webhooks/YOUR_WEBHOOK_URL"
```
