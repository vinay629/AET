# M5.2 Live Pilot Implementation Plan

## Overview

M5.2 is the **Live Pilot** stage of BAET — a tiny-capital live trading experiment
with strict risk limits and full compliance logging. This document describes the
architecture, implementation status, and deployment checklist.

## Risk Limits

| Limit | Value | Description |
|-------|-------|-------------|
| Daily Loss | $10.00 | Stop trading if daily loss exceeds $10 |
| Single Position Loss | $5.00 | Close position if loss exceeds $5 |
| Consecutive Losses | 3 | Stop after 3 consecutive losing trades |
| Max Concurrent Positions | 2 | Maximum 2 open positions at once |
| Max Daily Trades | 5 | Maximum 5 trades per day |
| Capital at Risk | $50.00 | Total capital allocated to M5.2 pilot |

## Deployment

### Pre-Launch
1. Run full test suite: `python -m pytest tests/ -v`
2. Verify paper trading stability (24h observation)
3. Configure notification channels
4. Set up audit log rotation
5. Confirm Binance testnet connectivity

### Launch
1. Enable `live.enabled=true` in config
2. Set `live.testnet=true` initially
3. Start with `baet paper-trade` to verify loop
4. Monitor audit logs: `logs/audit/`
5. Verify notifications are received

### Post-Launch
1. Daily review of audit trail
2. Monitor risk limit status
3. Review daily summary notifications
4. Adjust limits as needed
